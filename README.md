# Сайт игрового канала

## Что где
- index.html — сам сайт (главная, видео, о канале, контакты).
- admin.html — админ-панель. Пароль: Deadly00wolf.
- config.json — все настройки: тексты, ссылки, цвета, channelId.
- videos.json — кэш видео. Его заполняет автоматика, руками править не нужно.
- fetch_videos.py — скрипт, который качает ленту YouTube на серверах GitHub.
- .github/workflows/update-videos.yml — запускает скрипт каждые 3 часа.

## Установка
1. Загрузите index.html, admin.html, fetch_videos.py в корень репозитория (Add file → Upload files).
2. update-videos.yml загрузите по пути `.github/workflows/update-videos.yml`: на GitHub выберите
   Add file → Create new file и в поле имени файла впишите полный путь с точкой в начале.
3. config.json — только если в репозитории ещё нет своего. Если там уже лежит ваш конфиг с реальными
   ссылками и channelId — НЕ заменяйте его, оставьте свой.
4. Откройте вкладку Actions → слева «Update videos» → Run workflow → зелёная кнопка Run.
5. Через минуту videos.json заполнится видео. Обновите сайт: Ctrl+F5.

Дальше лента обновляется сама каждые 3 часа.

## Если видео не появились
1. Откройте вкладку Actions в репозитории:
   - пункта «Update videos» нет в списке слева → файл workflow лежит не в `.github/workflows/`,
     проверьте путь;
   - у последнего запуска красный крестик → откройте его и пришлите текст ошибки
     (обычно в шаге «Run python fetch_videos.py»);
   - галочка есть, а видео нет → подождите минуту и обновите сайт Ctrl+F5.
2. Откройте videos.json в репозитории. Если внутри `"videos": []` — значит channelId не найден:
   откройте config.json и убедитесь, что там есть поле channelId (строка, начинающаяся с UC).
3. Сайт открывайте по адресу GitHub Pages (username.github.io/имя-репозитория), а не как файл
   с диска: при открытии через file:// видео не загрузятся.

## Черновиков больше нет
Механизм черновиков полностью удалён из сайта и админки. Сайт всегда показывает опубликованный
config.json из репозитория — ровно то, что видят посетители. Старый черновик, который мог
сохраниться в браузере ранее, сайт просто игнорирует.

Порядок правок теперь один: админ-панель → изменить поля → «Скачать config.json» →
загрузить файл в репозиторий → Ctrl+F5.
