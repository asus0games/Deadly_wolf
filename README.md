# Сайт-визитка канала Deadly_wolf 🐺

Тёмный одностраничный сайт с вкладками для YouTube-канала [@Deadly00wolf](https://www.youtube.com/@Deadly00wolf).

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт |
| `config.json` | настройки: тексты, ссылки, цвета |
| `admin.html` | админ-панель (за паролем) |
| `README.md` | эта инструкция |

## Установка на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите все 4 файла (Add file → Upload files).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ваш-ник.github.io/имя-репозитория/`.

## Вход в админку

Откройте `admin.html`. Пароль по умолчанию: **Deadly00wolf**.

Пароль проверяется по SHA-256-хешу прямо в браузере. Это защита от случайных
посетителей, а не полноценная безопасность: репозиторий и сам сайт публичны,
поэтому технически подкованный человек хеш найдёт. Личные данные и доступы
через админку не передавайте и не храните в ней.

### Как сменить пароль

Сгенерируйте новый хеш (например, на любом онлайн-сервисе «SHA-256 generator»)
от строки `Deadly00wolf:ВАШ_НОВЫЙ_ПАРОЛЬ` — именно с этим префиксом!
Откройте `admin.html`, найдите в начале скрипта строку

```js
const PW_HASH = "59955d93...";
```

и замените хеш на свой. Затем закоммитьте файл.

## Как обновить сайт

- **Видео** подтягиваются автоматически из RSS-ленты канала — заливайте ролики на YouTube, на сайте они появятся сами.
- **Тексты, ссылки, цвета**: войдите в `admin.html`, отредактируйте, нажмите «Скачать config.json» и загрузите файл в репозиторий (Add file → Upload files → Commit changes).

## Структура config.json

```json
{
  "siteTitle": "Deadly_wolf",
  "tagline": "подпись",
  "aboutText": "текст о канале",
  "links": [{ "icon": "telegram", "name": "Telegram", "url": "https://t.me/..." }],
  "accent1": "#8b5cf6",
  "accent2": "#e11d48"
}
```

Возможные `icon`: `telegram`, `vk`, `discord`, `youtube`, `boosty`, `twitch`, `steam`, `donationalerts`, `other`.
