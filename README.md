# Сайт канала Deadly_wolf

Статический сайт на GitHub Pages: главная, вкладка «Видео», «О канале», «Контакты» и админ-панель.

## Файлы

- `index.html` — сам сайт.
- `admin.html` — админ-панель (пароль: **Deadly00wolf**).
- `config.json` — настройки: названия, описания, ссылки (включая Discord), цвета.
- `videos.json` — кэш ленты YouTube. Заполняется автоматически, руками не трогать.
- `fetch_videos.py` — скрипт, который скачивает ленту YouTube в `videos.json`.
- `.github/workflows/update-videos.yml` — правило автозапуска раз в 3 часа.

## Почему видео больше не «пропадают»

Раньше сайт брал ленту YouTube через браузер посетителя (сервисы-посредники rss2json и т. п.).
Теперь ленту скачивают серверы GitHub по расписанию и складывают её в файл `videos.json`,
а сайт читает этот файл первым. Прокси остались только как запасной вариант.

## Первый запуск после загрузки файлов

1. Загрузите все файлы в репозиторий. Файл `update-videos.yml` должен лежать по пути
   `.github/workflows/update-videos.yml` (в GitHub при «Add file» → «Create new file» введите путь с точками и слэшем).
2. Откройте вкладку **Actions** в репозитории → слева **Update videos** → **Run workflow** → Run.
3. Через минуту появится заполненный `videos.json`. Обновите сайт через Ctrl+F5.

## Смена пароля админки

Пароль хранится в `admin.html` как SHA-256-хеш в строке `var HASH = '...'`.
Чтобы сменить пароль, посчитайте хеш нового пароля на сайте emn178/online-tools (SHA-256, lowercase hex)
и замените строку. Текущий хеш соответствует паролю `Deadly00wolf`.

## Discord-ссылка

В `config.json` в блоке `links` есть запись с `"type": "discord"`. Впишите туда реальную ссылку
приглашения на сервер (вида `https://discord.gg/xxxx`), иначе кнопка будет вести в никуда.
