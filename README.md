# Сайт канала Deadly_wolf (@Deadly00wolf)

Одностраничный сайт-визитка YouTube-канала: вкладки «Главная / Видео / О канале / Контакты»,
автоматическая подгрузка новых видео через RSS и админ-панель для правки контента.

## Как выложить на GitHub Pages (5 минут)

1. Создайте репозиторий на GitHub (например `deadlywolf-site`).
2. Загрузите в него 3 файла: `index.html`, `admin.html`, `config.json`.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_НИК.github.io/deadlywolf-site/`.

## Как обновлять данные (ссылки, тексты, цвета)

**Способ 1 — через админ-панель (проще всего):**
- откройте на сайте страницу `admin.html`;
- измените что нужно, нажмите «⬇ Скачать config.json»;
- в репозитории нажмите **Add file → Upload files**, перетащите скачанный `config.json`, подтвердите **Commit changes**;
- через минуту сайт обновится у всех (если не обновился — Ctrl+F5).

**Способ 2 — вручную:** откройте `config.json` в репозитории, нажмите карандаш (Edit), поправьте поля и закоммитьте.

Структура ссылок в `config.json`:
```json
{ "type": "telegram", "title": "Мой Telegram", "url": "https://t.me/...", "note": "новости канала" }
```
Типы: `youtube`, `telegram`, `vk`, `discord`, `twitch`, `tiktok`, `boosty`, `rutube`, `other`.

## Как обновляются видео

Сайт сам подтягивает последние видео канала по RSS
(`https://www.youtube.com/feeds/videos.xml?channel_id=UCN3_YEiDPE_tUzS0vkQoYYg`)
через бесплатный сервис rss2json, с запасным вариантом через allorigins. Ничего обновлять вручную не нужно —
новое видео на YouTube появится на сайте автоматически в течение нескольких минут.

⚠ Если видео перестали подгружаться — проверьте, что ID канала в `config.json` верный
(его можно взять из RSS-ссылки выше).

## Файлы

- `index.html` — сам сайт (не требует правок).
- `config.json` — все настройки и контент: редактируйте здесь.
- `admin.html` — удобная панель для редактирования config.json.

Локальный предпросмотр: некоторые браузеры блокируют `fetch` при открытии файла с диска.
Откройте папку сайта через `python -m http.server` или проверяйте на GitHub Pages.
