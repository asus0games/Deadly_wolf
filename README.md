# Сайт-визитка канала Deadly_wolf

Тёмный одностраничный сайт с вкладками, живой лентой видео с YouTube и
админ-панелью для правки контента. Работает полностью на GitHub Pages,
без серверов и без затрат.

## Файлы

- `index.html` — сам сайт (вкладки: Главная, Видео, О канале, Контакты).
- `admin.html` — админ-панель с паролем.
- `config.json` — все настройки сайта: тексты, ссылки, цвета.
- `README.md` — эта инструкция.

## Как выложить сайт

1. Создайте репозиторий на GitHub и загрузите туда все 4 файла
   (Add file → Upload files).
2. Откройте Settings → Pages → Source: «Deploy from a branch» →
   Branch: `main`, папка `/(root)` → Save.
3. Через 1–2 минуты сайт появится по адресу
   `https://ваш-ник.github.io/имя-репозитория/`.

## Видео

Сайт берёт список видео из RSS-ленты канала по `channelId` из config.json.
Новое видео появляется на сайте само через несколько минут после публикации.
Лента подгружается через три сервиса по очереди (rss2json → allorigins →
corsproxy): если один лежит, сайт молча пробует следующий. Если недоступны
все — на сайте появляется честное сообщение со ссылкой на канал.

Если видео пропали: откройте в браузере
`https://api.rss2json.com/v1/api.json?rss_url=https://www.youtube.com/feeds/videos.xml?channel_id=UCN3_YEiDPE_tUzS0vkQoYYg`
— пустой ответ означает, что «болеет» rss2json (остальные источники
подхватятся сами).

## Админ-панель

Открывается по адресу `ваш-сайт/admin.html`. Вход по паролю.
После входа доступно:

- правка всех полей config.json (форма строится по фактическому файлу);
- список ссылок: добавление и удаление элементов, любое количество;
- цвета — с выбором через палитру;
- кнопка «+ поле» — добавить новые настройки любого типа;
- «Сохранить в браузере» — предпросмотр изменений на index.html
  в своём браузере до публикации;
- «Скачать config.json» — готовый файл для публикации.

**Как опубликовать изменения:** скачайте config.json и загрузите его в
репозиторий (Add file → Upload files). Через минуту изменения увидят все.

**Важно:** черновик из админки виден только в вашем браузере. Если захотите
вернуться к опубликованной версии — в админке есть кнопка «Убрать черновик»,
а на самом сайте — такая же кнопка в жёлтом баннере.

## Пароль

Пароль по умолчанию: `Deadly00wolf`. В коде admin.html хранится только
SHA-256-отпечаток строки `Deadly00wolf:<пароль>`, а не сам пароль.

**Как сменить пароль:** вычислите SHA-256 от строки
`Deadly00wolf:ваш-новый-пароль` (любой онлайн-генератор SHA-256), найдите
в admin.html строку `const PW_HASH = "…"` (переменная `PW_HASH`) и вставьте
свой хеш. Пароль лучше задавать латиницей и цифрами.

**Честное предупреждение:** сайт на GitHub Pages полностью публичный,
включая admin.html. Такой пароль отсекает случайных посетителей, но
технически подкованный человек может достать хеш из кода и подобрать пароль.
Секретов в конфиге не храните — только ссылки и тексты.

## Свой домен (бесплатно)

Бесплатный поддомен вида `ваше-имя.is-a.dev` можно получить через
github.com/is-a-dev/register: создайте JSON-файл с CNAME-записью на
`ваш-ник.github.io` и отправьте Pull Request. Затем в репозитории:
Settings → Pages → Custom domain → вписать домен → Save → после
пропагации DNS включить Enforce HTTPS.

## Проверка локально

Просто двойной клик по index.html не подойдёт — браузер блокирует чтение
config.json с диска. Локально запускайте так:

    python -m http.server

и открывайте `http://localhost:8000`. Или проверяйте сразу на GitHub Pages.
