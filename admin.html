Порядок публикации правок: измените поля → «Скачать config.json» → загрузите файл в репозиторий GitHub (Add file → Upload files, замените старый) → обновите сайт через Ctrl+F5. Черновиков больше нет: сайт всегда показывает опубликованную версию из репозитория, и её видят все посетители.
