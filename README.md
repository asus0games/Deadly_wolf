# Сайт канала Deadly_wolf

Сайт-визитка для YouTube-канала. Работает на GitHub Pages, без серверов и баз данных.

## Файлы

- **index.html** — сам сайт (вкладки: Главная, Видео, О канале, Контакты).
- **config.json** — все настройки: название, тексты, ссылки, цвета.
- **admin.html** — админ-панель для правки config.json (защищена паролем).

## Как выложить сайт

1. Загрузите все три файла в репозиторий (Add file → Upload files).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → Save.
3. Через пару минут сайт откроется по адресу `https://ваш-ник.github.io/имя-репозитория/`.

## Как менять контент

1. Откройте `адрес-сайта/admin.html` в браузере.
2. Введите пароль администратора.
3. Панель сама прочитает config.json с сайта и покажет поля для правки: тексты,
   ссылки (можно добавлять и удалять), цвета оформления. Кнопка «+ Поле» добавляет
   новые настройки.
4. Нажмите **«Сохранить в браузере»** — правки сразу видны на index.html в вашем
   браузере (черновик, виден только вам).
5. Когда всё устраивает — **«Скачать config.json»** и загрузите файл в репозиторий
   (Add file → Upload files → Commit changes). Через минуту изменения увидят все.

## Видео обновляются сами

Сайт подтягивает последние ролики канала через RSS-ленту YouTube
(сервис rss2json, запасной вариант — allorigins). Залили новое видео —
оно появится на сайте само, вручную ничего менять не нужно.

## О пароле админки

В коде admin.html хранится не пароль, а его SHA-256-отпечаток, поэтому пароль
нельзя прочитать из исходника напрямую. Помните: GitHub Pages — публичный хостинг,
весь код сайта виден всем. Такой пароль отсекает случайных посетителей,
но не защищает от технически подкованного человека. Не храните в админке
настоящие секреты (пароли от аккаунтов и т. п.).

### Как сменить пароль

Посчитайте SHA-256 от строки вида `Deadly00wolf:ваш-новый-пароль`
(префикс `Deadly00wolf:` обязателен), затем в admin.html замените строку
`const PW_HASH = "..."` на новый хеш. Посчитать хеш можно любым онлайн-генератором
SHA-256 или командой `echo -n "Deadly00wolf:новыйпароль" | sha256sum`.

## Локальный предпросмотр

Просто открыть index.html двойным кликом нельзя — браузер блокирует чтение
config.json и видео. Для локальной проверки запустите в папке проекта:

```
python -m http.server 8000
```

и откройте `http://localhost:8000`.
